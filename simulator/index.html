How to use the Simulator

1. Select a method (Activation Maximisation / DeepDream)

2. Choose a CNN layer and filter

3. Adjust parameters using sliders

4. Click "Update Visualization"

This simulator uses precomputed outputs to demonstrate how CNN visualisation techniques behave under different parameters.

This simulator was developed by David Farrugia as part of the final project for full completion of the ARI5118 - Deep Learning for Computer Vision study unit at the University of Malta.
